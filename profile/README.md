# ⬛ NoireBox

**The flight data recorder for AI agents.**

Every decision an AI agent takes is sealed into a tamper-evident journal —
hash-chained, Ed25519-signed, anchored to outside witnesses — and exports as
evidence anyone can verify offline, without trusting the operator.

| | |
|---|---|
| 📦 **The journal** | [noirebox/noirebox](https://github.com/noirebox/noirebox) — `pip install noirebox`, MIT |
| 🐳 **Docker** | `ghcr.io/noirebox/noirebox:latest` |
| ✅ **Third-party verification** | [noirebox-verify](https://github.com/marketplace/actions/noirebox-verify) — gate your CI on journal integrity |
| 🇪🇺 **Compliance mapping** | EU AI Act art. 12 · GDPR art. 5(2) · eIDAS art. 41 — [docs](https://github.com/noirebox/noirebox/blob/main/docs/COMPLIANCE-EU.md) |

**Honest scope:** NoireBox proves a record was *not altered* and *when it
existed*. It does not prove the record was *true* when written. A proof
tool, not a talisman.
